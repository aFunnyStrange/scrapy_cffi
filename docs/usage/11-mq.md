# 1.Introduction

`scrapy_cffi.mq` provides adapter classes with retry/reconnect support for `RabbitMQ` and `Kafka`.

Install dependencies first:

```bash
pip install aio_pika
pip install aiokafka
```

Broker connection settings live in `settings.RABBITMQ_INFO` and `settings.KAFKA_INFO` (see [1-settings.md](./1-settings.md)). Redis scheduler/dedup uses `settings.REDIS_INFO`.

# 2. Local infra templates (`geninfra`)

Generate Docker Compose stacks for local development:

```bash
scrapy-cffi geninfra
scrapy-cffi geninfra --redis sentinel --rabbitmq cluster --kafka cluster
scrapy-cffi geninfra --clean
```

Output defaults to `./infra/`:
- Baseline `docker-compose.yml` + `Dockerfile` (single-node)
- Optional subdirs: `redis-sentinel/`, `redis-cluster/`, `rabbitmq-cluster/`, `kafka-cluster/`
- `topology.example.toml` — map generated ports to `REDIS_INFO` / `RABBITMQ_INFO` / `KAFKA_INFO`

**Note:** Compose multi-container layouts simulate cluster/sentinel on one host. They are for integration testing and local dev, not a production multi-host deployment recipe.

CLI details: [0-start.md](./0-start.md#5geninfra).

# 3. Settings quick reference

## 3.1 Redis (scheduler / dedup / RedisSpider)

```python
settings.REDIS_INFO.MODE = "single"  # single | sentinel | cluster
settings.REDIS_INFO.URL = "redis://127.0.0.1:6379/0"

# Sentinel example
settings.REDIS_INFO.MODE = "sentinel"
settings.REDIS_INFO.SENTINELS = [("127.0.0.1", 26379)]
settings.REDIS_INFO.MASTER_NAME = "mymaster"

# Cluster example (startup nodes)
settings.REDIS_INFO.MODE = "cluster"
settings.REDIS_INFO.CLUSTER_NODES = [{"host": "127.0.0.1", "port": 7000}]
```

Stream ingress defaults (optional, decoupled from spider attrs): `settings.REDIS_STREAM_INFO` — see [1-settings.md](./1-settings.md#293-redis_stream_info) and [2-spiders.md](./2-spiders.md#223-settingsredis_stream_info-project-wide-defaults).

## 3.2 RabbitMQ

```python
settings.RABBITMQ_INFO.URL = "amqp://guest:guest@127.0.0.1:5672/"
settings.RABBITMQ_INFO.MODE = "cluster"
settings.RABBITMQ_INFO.CLUSTER_NODES = [
    "amqp://guest:guest@127.0.0.1:5672/",
    "amqp://guest:guest@127.0.0.1:5673/",
]
settings.SCHEDULER = "scrapy_cffi.scheduler.RabbitMqScheduler"
```

## 3.3 Kafka

```python
settings.KAFKA_INFO.URL = "127.0.0.1:9092"
settings.KAFKA_INFO.MODE = "cluster"
settings.KAFKA_INFO.CLUSTER_NODES = ["127.0.0.1:9092", "127.0.0.1:9093"]
```

# 4. Integration tests

Unified broker test entry: `tests/test_broker/README.md`

Coverage:
- Redis: `single` / `sentinel` / `cluster`
- RabbitMQ: `single` / `cluster`
- Kafka: `single` / `cluster`

Stack assets: `tests/test_broker/stacks/{redis,rabbitmq,kafka}/`

Example (Linux/bash, from repo root):

```bash
docker compose -f tests/test_broker/stacks/redis/sentinel/docker-compose.yml up -d
python tests/test_broker/test_redis_broker.py sentinel
```

Legacy standalone dirs `tests/test_redis`, `tests/test_rabbitmq`, and `tests/test_kafka` were removed in 0.3.0; use `tests/test_broker` instead.
