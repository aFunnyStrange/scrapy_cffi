# 1.Introduction
scrapy_cffi.mq provides adapter frameworks with automatic retry and reconnection utility classes for `RabbitMQ` and `Kafka`.For using the `RabbitMQ` and `Kafka` utility classes, you need to install the dependencies manually:
```bash
pip install aio_pika
pip install aiokafka
```
